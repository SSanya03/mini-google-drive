# Mini Google Drive

A beginner-friendly web application project inspired by cloud file-storage platforms.

## Goal

Build a web application that allows users to register, log in, upload, view, download, and delete their files.

## Planned Technologies

- Python
- Flask
- HTML and CSS
- SQLite
- Git and GitHub

## Current Progress

- [x] Created the project folder
- [x] Initialized a local Git repository
- [ ] Built the first Flask route
- [ ] Implemented file upload
- [ ] Added user authentication
- [ ] Connected a database

## Learning Approach

This project is being developed step by step, with an emphasis on understanding web development, testing features, debugging, and documenting progress.
